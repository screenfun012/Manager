# 🚀 Potrosni Materijal - Standalone Web Application

## 📋 Preuzimanje i pokretanje

### **Za Mac/Linux:**
1. Skini sve fajlove u jedan folder
2. Otvori Terminal u tom folderu
3. Pokreni: `./start-app.sh`
4. Aplikacija će se otvoriti u browseru na `http://localhost:3000`

### **Za Windows:**
1. Skini sve fajlove u jedan folder
2. Otvori Command Prompt u tom folderu
3. Pokreni: `start-app.bat`
4. Aplikacija će se otvoriti u browseru na `http://localhost:3000`

## 🔧 Sistemski zahtevi

- **Node.js** (verzija 14 ili novija)
- **npm** (dolazi sa Node.js)
- **Browser** (Chrome, Firefox, Safari, Edge)

## 📦 Instalacija Node.js

### **Mac:**
1. Idi na https://nodejs.org/
2. Skini "LTS" verziju
3. Pokreni installer
4. Restart Terminal

### **Windows:**
1. Idi na https://nodejs.org/
2. Skini "LTS" verziju
3. Pokreni installer
4. Restart Command Prompt

## 🚨 Rešavanje problema

### **"Node.js nije instaliran" greška:**
- Instaliraj Node.js sa https://nodejs.org/
- Restart Terminal/Command Prompt

### **"npm nije instaliran" greška:**
- Node.js dolazi sa npm-om
- Reinstaliraj Node.js

### **"Port 3000 je zauzet" greška:**
- Zatvori druge aplikacije koje koriste port 3000
- Ili promeni port u `package.json`

### **"Backend server ne radi" greška:**
- Proveri da li je port 5001 slobodan
- Restart aplikaciju

## 📞 Podrška

Ako imaš problema:
1. Proveri da li su svi fajlovi preuzeti
2. Proveri da li je Node.js instaliran
3. Proveri da li su portovi 3000 i 5001 slobodni
4. Restart aplikaciju
